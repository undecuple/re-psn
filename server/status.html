What do these words mean?
connected
Connections open to the server right now. Normally one per player.
connections total
Every connection the server has accepted since it started, including ones that have closed and ones the server then turned away for a bad request. It only counts up, so it is higher than the number of players. Connections refused at a limit are not counted.
unlisted rooms
Invite-only rooms. The server counts them but never lists them.
Room
A group a player creates for a game so others can join it. Only public rooms are listed.
ID
The number the server gave the room.
Title
The game the room is for. It shows the game's name when the server knows it, and its title ID otherwise.
Members
The players in the room, out of its maximum. "(1 verified)" counts members whose network test the server has accepted. A number in ms is the delay the player reported for themselves; the server did not measure it.
Age
How long ago the room was created.
Leaderboard
Scores players have recorded for a game. Board is the leaderboard's number within the game, Entries is how many scores it holds, and Leader is the player with the best score, shown with that score.
Relay
An optional mode where the server passes game traffic between players who cannot reach each other directly. Relay payload is the amount it has carried since the server started, not the network traffic of the machine.
Connection limit
The most connections the server allows open at once. "Unlimited" means no limit is set.
Refused connections
Connections the server turned away because too many were already open in total.
Per-address refusals
Connections the server turned away because one address already had too many open.
Request-rate refusals
Connections the server closed because they sent requests too fast.
